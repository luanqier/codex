# Continuity Method

## Chapter event ledger

Before scripting, record:

- Incoming location, time, character state, knowledge, objective, and unresolved threat.
- Source events in strict causal order.
- Safe dialogue worth preserving, with prohibited source wording mapped only to its dignified artistic replacement.
- Required visual assets.
- Final state and next-chapter hook.

## Segment transition contract

For every neighboring pair of segments, verify:

| Field | End of prior segment | Start of next segment |
| --- | --- | --- |
| Location/time | Explicit state | Same state or motivated change |
| Character position | Last visible position | Compatible opening position |
| Action | Finished or intentionally suspended | Continued, reacted to, or cleanly cut away |
| Information | Newly learned fact | Changes the next decision or reaction |
| Prop | Owner and location | Same owner/location unless transfer is shown |
| Emotion | Last emotional pressure | Preserved or visibly transformed |
| Light/weather | Last condition | Continuous or motivated transition |

Continuity does not require literal tail-frame transfer. Use a motivated bridge:

- Direct action carryover.
- Reaction cut.
- Eyeline match.
- Sound bridge.
- Match cut by shape, color, motion, or symbolic object.
- Establishing cut after clearly implied travel or time transition.
- Cause-and-effect cut from decision to consequence.

Reject a transition when the viewer must invent a missing action, location change, relationship shift, or piece of information.

## Coverage check

Create a source-event-to-segment map. Every required event must map to at least one segment. Added material must clarify an existing event rather than create a new story branch.
