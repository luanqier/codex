# 打斗专用流程

本模块为打斗段的输出权威，覆盖主Skill的六字段、对白保留、宫格、图1声明和文戏目录要求。

## 接收主流程信息
接收原文范围、段ID与时长、画风画幅、人物/场景/道具参考路径与版本、双方目标、起始站位朝向与距离、武器持有手、能力限制、环境障碍、既定战斗结果和下一文戏入口。复用已有信息，只对影响结果且无法推断的缺失项追问。

## 执行
1. 忠实改编保留能力、动机与结果；原创按用户设定。沿用入口的打斗导演协议，编排“发起—应对—可见结果—新站位”。
2. 默认零对白、零旁白，去掉喊招、嘲讽、战斗解说。必要剧情信息移至前后文戏；无法移出的极短口令仅在停顿保留。
3. 按动作完成时间写连续时间线，每区间用连贯文字描述攻防、镜头与同步音效。时间无重叠、无空档，合计等于本段时长；不得机械均分。较长战斗拆为连续段。
4. 只交脚本及人物、场景、必要道具参考图。已批准图优先复用并复制到交付目录；缺失时生成独立参考图。禁止生成打斗宫格、逐镜拼图、逐镜配图或参考分镜图，图片数量不与镜头数绑定。
5. 用户只要脚本时不扩展出图；要求制作打斗段或完整章时交实际参考图。工具不可用时标明未完成，不用绘图提示词冒充已出图。
6. 检查身份、空间、动作、时长和参考绑定，落盘后回传结束状态与接续点。

## 独立输出格式
不使用主Skill“主体、动作、运镜、风格、对白/旁白、声音与同步”六字段，也不写“图1是参考分镜图”。使用：

# 打斗段 F01｜15秒
视觉设定：项目画风、画幅、光线与角色版本。
参考绑定：人物A=参考图/人物A_v1.png；人物B=参考图/人物B_v1.png；场景=参考图/庭院_v1.png
开场状态：双方站位、朝向、距离、武器与环境障碍。
战斗目标与既定结果：双方目标及原文支持的结果。

动作时间线
[00.0–03.0s] 连贯写明发起者、轨迹、对方应对和落点；同时写构图、跟拍方式与同步声效。
[03.0–08.0s] 承接上一落点，呈现下一轮攻防与可见反馈。
[08.0–12.0s] 推进局势变化，保持武器、轴线与能力一致。
[12.0–15.0s] 确认本段结果，落到可供后续承接的姿势与位置。

结束与接续：双方位置/朝向、持有物、体力或能力变化、环境变化、结果、下一段入口。

上述时长仅为格式示例，不照抄节奏或镜头数。无台词时省略台词区；确需短台词时只加一个段级“保留短台词”条目并注明时间点。
参考绑定必须指向实际永久文件；草稿未就绪时标“待生成”，不得虚构已批准路径。

## 目录、验收与回传
- 打斗段/第NN段/打斗脚本.txt
- 打斗段/第NN段/参考图/人物、场景、必要道具图片

生产索引按全章顺序记录文戏/打斗、段ID、路径、时长、完成状态和接续点。混合章节ZIP含两类目录及索引，检查文件齐全、图绑定、时间线、跨段状态与ZIP可打开。
旧文戏校验器若不支持打斗，只检查其适用的文戏范围；不得为通过旧校验器伪造宫格或六字段，也不能把文戏校验通过称为全章通过。
回传主流程：段ID、规划时长、脚本/参考图路径、结束状态、接续点和未完成项。回传记录放索引，不污染打斗脚本。
