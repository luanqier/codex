# V7 特效视觉库（可选）

只在原文或项目已授权武器光效、能量、法术时使用。它定义表达方法，不提供角色新能力，不提高威力或破坏规模，不强制写实战斗加能量。

## 描述结构与视觉尺度
先锁定角色/武器已有的颜色、材质、形态和发出位置，再按动作写路径与落点。复杂特效可用“主体结构—边缘变化—对环境的响应”；小特效只写必要层次，不强制三层或三混合比例。
描述内部有什么、如何运动：分叉电弧沿武器延伸、冰片随斩击旋转、水流卷成刃面、墨色边缘随运动散开。比喻最多选一个，并接实际运动；避免只写“一道巨大光”。
尺度优先用画面和熟悉物体比较：横跨双方之间、扫过整条廊道、人物在远处成为小剪影。需要时写前景参照和机位关系，保持原文力量；不把厘米、米速、Bloom、精确百分比或渲染引擎名称当作必然生效的模型参数。用户提供有意义尺寸或平台明确支持的参数时保留并结合可见表达。

## 可选材质方向
| 已授权属性 | 主体与内部结构 | 边缘与环境响应 |
|---|---|---|
| 雷 | 分叉电弧，亮芯沿既有载体跳动 | 边缘细小闪光，邻近表面短暂映亮 |
| 火 | 明亮火芯和随运动翻卷的火舌 | 暗烟与热扰动按风向延续 |
| 冰 | 半透明晶片或有棱面的冰刃 | 细霜与寒雾随轨迹扩散 |
| 水 | 有折射层次的水刃与卷流 | 边缘细水珠，落点出现对应涟漪 |
| 风 | 空气偏折或旋转气流 | 衣摆、落叶和尘线显示方向 |
| 土 | 层叠岩片与裂隙 | 尘土颗粒按受力和重力落下 |
| 金属 | 刃口短促冷光、金属反射 | 碰撞火花与装备震颤 |
| 水墨 | 有浓淡和飞白的流动墨痕 | 边缘散开，余痕逐渐消散 |

颜色遵从批准资产和角色属性，不把“刀=黑红紫、剑=冰蓝”等示例变成绑定规则。不把物理材质响应自动升级为超自然力量。

## 特效与动作
- 特效应帮助识别角色既有力量与招式状态：蓄势、发出、受阻、命中或消散具有区别，不要求全程发光。局势升级可改变已授权能量的集中度、路径或覆盖范围，不自动提高能力等级。
- 独立飞行法术与真实肢体分开描述；施术者位置、真实手臂长度和法术轨迹各自连续。角色被击飞后按受力惯性运动，法术不能一直牵着其身体走。
- 能量来源可以是武器、身体、既有法阵或装置，按剧情交代；沿载体附着仅在设定适合时用，不强制身体—手臂—武器全部发光。
- 出招写目标和轨迹；落空、格挡、抵消或命中都交代结果，消耗与余波延续到下一拍。
- 拖尾沿真实运动方向展开，主体清晰；速度快可相应延长，不用拖尾替代身体位移。
- 环境损伤、碎片和残留不会切镜后复原。逐级破坏先确认场景与原文允许，保留用于定位的刚性物体。
- 彩色光映到人物和环境但不遮脸、不吞掉接触；复杂爆发可分亮芯、主色雾化和外层碎片，避免满屏同色。
- 冷暖或明暗对比按项目画风选择，不强制每场四色、全剧同配方或过度泛光。

有批准图时简写稳定外观，把文字留给动作、状态、速度和接触。明确各图控制身份、场景或道具；多人物映射清楚，必要识别锚点可保留，不实施无条件“有图零外观”。
这些方法不附带跨模型有效性保证。实际生成后检查材质、尺度、来源、轨迹、连续性和动作可读性。
