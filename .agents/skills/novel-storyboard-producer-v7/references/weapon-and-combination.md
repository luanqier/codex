# V7 兵器机制与连招参考

按角色已有能力和风格选方法。以下是影视动作编排方向，不是实际格斗训练；不引入新力量、武器或终结结果。原附件作者禁止连续直拳等个人偏好不成为本用户的默认规则。

## 角色距离与动作族
| 类型 | 可设计的距离选择 | 攻击与防守方向 | 连贯接口 |
|---|---|---|---|
| 徒手 | 靠近、错身、脱离，再争取位置 | 试探、拨挡、侧让、推开、绊阻、非图形化碰撞 | 承接重心转移与对方应对，不原地轮流表演 |
| 刀 | 利用斩击范围，错开来势后回到可控距离 | 劈、斜斩、横扫、下撩、斜架与导开 | 偏转带出转胯，挥击余势接追步或卸力 |
| 剑 | 围绕方向和空当变化，而非固定连续大劈 | 刺、拨、撩、截、压与撤 | 对方格挡让路径改变，接换线或侧跨 |
| 枪 | 保持长兵器可用距离，近身后需重建间距 | 前刺、上挑、横扫、架挡；枪头、杆身与持握明确 | 导偏后回到枪头对准目标，进退随路径 |
| 棍 | 让较长端有挥动空间，受贴近时体现限制 | 劈、扫、戳、挑、点，配架、拦、压、拨 | 上下或攻守变化由对方抬挡、让位或持械状态触发 |
| 双持 | 两件数量和持有手持续一致，职责可不同 | 一侧限制来势，另一侧追空当或掩护脱离 | 不让两件同时完成互不相关的复杂招式 |
| 弓箭 | 以视线、射线、距离和掩体争取释放条件 | 搭箭、举弓、引弓、释放，箭离弦后独立追踪 | 落点后换位或补给，贴近时按既有能力应对 |
| 软兵 | 需要摆动空间，张力、缠绕和回收连续 | 甩出、偏转、约束、回拉或收回 | 链/绳的两端和张力明确，不凭空换目标 |
| 远程法术 | 保留发出者、发出位置、目标和能力边界 | 直线、弧线、展开、抵消或授权追踪 | 释放后能量与真人身体分开记录，资源不重置 |

## 起动—发力—轨迹—结果
只选改变画面的身体信息。地面位移有支撑脚和落点；兵器动作有持有手、握持位置、运动方向与回收状态。可用蹬地→转胯→肩臂推进→兵器前端到达目标，或卸力→侧跨→重新指向空当；不把发力链当每招必须完整复述的术语表。

## 连招机制
| 机制 | 前一拍制造的条件 | 后一拍如何发生 |
|---|---|---|
| 拦后反击 | 来势被导向身侧 | 顺偏转抢新的攻击线 |
| 高低变化 | 对手抬挡、重心升高或主动让位 | 换高度或落点，但保留原文允许的目标与结果 |
| 佯攻变向 | 对手做出可见防守选择 | 利用其反应改变路线，不无来源瞬移 |
| 距离抢夺 | 长兵器被贴近或短兵器被拉开 | 通过步法、障碍或卸力重建优势距离 |
| 余势再利用 | 格挡、撤步或旋身留下运动方向 | 延续动量或用可见支撑改变方向 |
| 夺位而非命中 | 攻击迫使对方让出路线 | 抢通路、护住目标或结束追逐 |

连招结束可以保持压力、脱离、停稳判断或确认结果，不强制“起手—终结”或固定1–2秒内几招。原文要求一击结束时不扩展回合。

## 容易混淆的机制
- 持握圆弧下劈：握持点与手臂控制作为旋转关系，攻击端走弧线；写起始姿态、支点、方向和落点，不用“向下砸”替代。
- 武器整体坠落：只有释放、投掷或法术授权时，实体脱离持握整体下降；写释放时点、姿态和落点，不同时仍握在手里。
- 巨型化：先确认能力，写哪件实体变大、哪一端仍被控制、回缩/消散如何发生；不自动让人物手臂或全身一起变大。
- 离体掌印/剑气：人物本体位置、正常身体范围、法术起点与独立轨迹分别记录；击飞人物的惯性轨迹也独立，法术不能无说明附着拖拽身体。
- 弓箭：离弦之后弓留在持有者手中，箭独立飞行；跟踪、穿透、分裂或巨大化需要原文授权，不因采用箭术库而获得。
- 远程效果与受击：触碰法术、身体离地、轨迹、落地、场地变化分别有因果；若效果形成坑，明确由法术触地还是身体撞击造成，禁止同一效果在结果段凭空再次施放。接触后余势触地须由此前轨迹或原文授权变化连续导出，不为指定落点新增追踪、转向或牵引能力。

复杂关键动作可在用户请求动作设计或生成辅助图时绘制独立机制示意：起始位→轨迹→落点、握持/控制点、真人与法术分别着色。机制图不等于角色批准图，不自动生成逐镜宫格，不强制额外出图。
