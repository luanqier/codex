# V7 空间战术

场地首先服务目标：护门、争夺、拖延、突围、追击或摆脱。只用原文/资产中已存在，或不改变关键剧情的合理场地细节；不凭空安排能决定胜负的出口、法器或援军。

## 距离与路线
建立双方位置、朝向、可通行路线、障碍、落差、退路、持械空间和既定结束位置。每次位移说明原因、起点、路径、支撑或授权飞行依据、落点和得到/失去的优势。
长兵器角色可维持距离，短兵器角色可抢近；角色能力受限时行动范围相应减小。多人按当前主要发起与应对组织，不让所有人同时做无关招式。

## 场景参与方法
| 用法 | 动作理由 | 连续性检查 |
|---|---|---|
| 掩体 | 隔开视线、改变攻击线、争取退出 | 角色确实到达掩体，射线不能穿透未授权实体 |
| 支撑点 | 蹬墙、踩柱、落脚变向 | 接触、受力和落点可见，结构和能力允许 |
| 狭窄空间 | 限制兵器摆动或人数优势 | 不忽略墙面、门框与武器长度 |
| 高低落差 | 争取视线、退路、进入或退出 | 跳起、下落或授权飞行有过渡，不自动漂浮 |
| 可移动物 | 阻挡、改变路线或制造接触 | 移动后位置更新，不能每镜归位 |
| 损伤地形 | 改变支撑和可通行路线 | 已破门、坑、碎物继承，不自动恢复 |

换场只在剧情或战术需要时发生，不计算“时长÷5”安排最少地点数。同一场地可以通过距离、朝向、障碍两侧与高低位置发生丰富变化。

## 状态回传
记位置、朝向、余势/停稳姿态、持有物、体力或资源、环境损伤、视线和后续入口。段末镜头可以用于确认阶段结果，不必总做远景或离场。切入文戏时保留未解除压力和实际位置。
