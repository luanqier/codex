# V7 动作摄影

镜头表达角色选择、距离、接触、失衡和结果。把机位当设计工具，不把术语数量或复杂度当质量指标。

## 按阶段选镜
| 阶段 | 要回答的问题 | 可选镜头 |
|---|---|---|
| 对峙/试探 | 双方目的和距离是什么 | 双人中景、过肩、必要视线特写 |
| 逼近/追逐 | 路线、障碍与间距怎么变 | 侧向/侧后跟拍，必要高位交代路线 |
| 接触/格挡 | 谁接住哪条攻击线 | 同轴可读中景、短促接触特写后回接 |
| 破防/反制 | 防线如何打开，空当来自哪里 | 跟住武器偏转、脚步与肩胯，切到应对者 |
| 巨型效果/远攻 | 发出者、轨迹与落点如何关联 | 过肩、路径全景、落点构图 |
| 结果/接续 | 谁获得优势，后续在哪发生 | 稳定中全景、随退移揭示环境或出口 |

人物、兵器或法术是不同跟随目标，选择一个主要目标，不让摄影机同时围绕所有主体旋转。焦段可作为辅助语言，必须结合距离与构图；不把特定毫米数当镜头效果保证。

## 可选组合
- 跟住逼近→短促看接触→随退移回到双方关系，表达一次交换。
- 用同一轴侧向跟拍维持两人间距→对方换位时调整构图，表达持续压制。
- 下落路线与落点同框→接触后跟随卸力→稳定确认状态，表达跳落。
- 已授权大招显露来源→跟住路径→拉开展示影响范围，表达尺度。
- 前景遮挡或动作匹配切承接同一动作，保留方向、速度和姿态；清楚硬切也可以，不强制爆闪转场。

## 复杂摄影的替代选择
| 强表现选项 | 较简单的替代 |
|---|---|
| 大幅环绕 | 同轴弧形跟随或侧向平移 |
| 高空俯冲穿行 | 低角度跟随接续落点景 |
| 滑动变焦 | 普通推近结合人物/背景关系 |
| 剧烈滚转震动 | 短促后挫后稳定 |
| 长慢镜 | 仅关键动作短暂放缓再恢复 |

选择由剧情、画风、动作复杂度及用户要求决定；不把替代镜头与原镜头同时写进同一次生成指令。

## 身体动作与镜头速度
普通交锋不默认长慢环绕，突进时可用距离快速缩短、前景掠过、衣摆惯性和定向跟拍表达速度。慢镜用于关键闪避或情绪/力量转折，不强制0.25秒切镜、720度旋转或永久机位滞后。
开场按剧情选择动作、伏击、对峙或威慑，不默认急推冷笑。接触前后需能定位双方，不用闪光或近景藏掉应对。
严格一镜到底时保持连续机位，靠人物路线、纵深和构图变化组织；用户接受隐形剪辑时才使用遮挡藏切。

## 声音与光影
环境声连续；动作声落在脚步、衣料、兵器接触和落地上；已有能量效果有对应声音。不同层按重要性让位，音乐遵从项目，参战对白不被覆盖。
颜色与光效遵从角色和场景，关键转折可用亮度或构图变化强调，不每击固定闪帧或每角色必带水墨气场。
