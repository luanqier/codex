# V6 连续攻防、速度与动作摄影

将“快、狠、有冲击力”转成可见动作关系。先让攻防成立，再增加镜头与效果。以下规则服从原文能力、剧情结果、身体状态、环境许可和用户节奏。

## 1. 每轮留下下一拍接口
写清谁发起、指向哪里、路径如何、对方怎么应对、接触/格挡/落空结果、双方落点，以及下一拍由什么触发。
闭环要求针对实际攻击或争夺，不要求禁锢、对峙、压制等待等区间凭空出招。无法反击者可通过尝试失败、保持被困、目光与姿态回应，既定限制继续有效。
上一招的偏转、退移、旋身、失衡、追击空当或距离变化成为下一招起点。连续交锋减少“收招—站好—重新蓄力”；保留剧情需要的恢复、判断、脱离和喘息，不让受限者无限反击。
可按当前人物重新设计：斜架引开来势→顺偏转转胯→对方侧跨抢外侧→借落脚反制。只借鉴衔接机制，不套固定连招。段末胜负未决时保留压力与接续，不强行安排终结技。

## 2. 写速度变化，少写空泛速度词
默认紧凑、可读的连续攻防。可以使用短促试探、骤然加速、极短接触强调、立即追击和结果收束；次序由剧情决定，不固定“轻轻重”、镜头数或每秒动作数。
- 起动：支撑脚蹬地、重心前压、双方距离迅速缩短；常规交锋开场已有效行动，伏击或对峙铺垫按原文保留。
- 加速：武器接近接触点时加快、错身后突然变向、掠过近处障碍；写开始与结束位置，避免漂移瞬移。
- 接触：关键碰撞短促强调，脚步与身体仍有受力；仅决定性接触可用极短视觉停顿，随后立即恢复正常速度。
- 余势：衣摆、头发、尘线或既有能量稍晚追上身体，武器回弹带出下一动作；不给每一击重复停顿、回放或震屏。
- 对比：攻击、接触、退移与判断具有不同速度；长起势、持续慢环绕、无目的恢复镜不占据普通交锋。
慢动作只在剧情要求或关键动作必须辨认时使用，默认不铺满战斗。力量受限、演武或用户指定慢节奏时，保留其真实速度与目的，不强制高速。

## 3. 位移落在支撑与路径上
地面动作交代支撑脚、重心方向、移动路径和落点；按环境选择跨步、侧移、蹬地、踩柱借力、踏壁折返或屋脊转向。反馈匹配材质与力量：鞋底摩擦、瓦片轻响、积尘扬起即可，不必每步踩裂地面。
空中动作或瞬移只有原文授权时使用，写清起动依据、轨迹或能力过渡、速度方向及落点。不能用“闪到背后”省略必要空间关系。

## 4. 身体、环境与镜头有先后反馈
关键碰撞选取能说明力量的反馈链：接触点→手臂/肩胯/躯干→支撑脚与位移→装备或环境→镜头反应。写清力从哪里来、朝哪里去，不要求每击五层齐全。
兵器交击可表现武器回弹、手腕偏转、肩胯转开、脚下滑移、衣摆惯性、短促金属声和尘线。重击可增加较明显失衡或镜头后挫；避免图形化伤害与无来源环境爆炸。
落空也有结果：攻击继续沿原轨迹、改变重心、露出空当、消耗已有资源，或接触原文允许的环境。并非每次落空都砸毁墙面。破坏由小到大只在剧情与力量允许时发生，并在后续继承。

## 5. 摄影机跟随动作目标
每个动作阶段选一个主要职责：交代距离、追随位移、看清接触、呈现反制、跟住退移或确认结果。描述机位、方向、速度和跟随对象；焦段有帮助时才写，不堆工程参数。
- 突进：侧向或侧后中景定向跟拍，距离迅速缩短仍可读。
- 接触：看得到双方与交击点的构图，可短促推近；不在即将接触时用遮挡藏掉动作。
- 反击：镜头因武器偏转或身体转向调整，保持前一拍的方向与状态。
- 位移：前景柱子或瓦片较快掠过，远景变化较小，提供速度参照；避免全画面模糊和糊脸。
- 重击：可短促后挫或沿受力方向跟移，随后重新稳定；不用持续滚转、失焦、随机震动遮掉结果。
镜头可有短暂追赶惯性，但始终能辨认目标和落点，不强制人物冲出画框、不规定永久滞后帧数。双人同框用于交代关系，单人追拍或接触特写用于重点；画外对手仍通过轨迹、声音或接回画面被定位。

## 6. 转场承接同一动作
按需用肩背、柱子、衣摆或尘土短暂遮挡接下一个机位，或以动作匹配切延续挥击/退移。遮挡前后保留方向、速度、姿势、位置、持有手和环境；不靠擦镜掩盖接触缺失。清楚的硬切可以使用，不强制所有转场爆闪。
每段开始继承上段尾部状态并立即继续需要的动作，不固定复制1–2秒前情。结尾确认结果或下一段入口，可运动中收势、停稳判断或离场，按剧情选择。

## 7. 同步声音与参战对白
脚步、破风、碰撞、落地和环境回响按可见动作先后发生；挥空不配命中声。重点碰撞可极短压低背景声后恢复，不能每击都把声音抽空。
保留参战角色开口对白，标时间、音色与开口。可并行的脚步、格挡与短句自然并行；不能并行的长句按实际时间安排。内心活动无独白音轨，用视线、呼吸、握持、重心或选择表达；第三方解说也不出声。音乐遵从项目设定，按需要为对白与接触声留空间。

## 8. 失败时只改主要变量
| 症状 | 优先改什么 |
|---|---|
| 一招一停、动作生硬 | 删无目的收招复位，补余势到下一拍的连接 |
| 全程缓慢 | 查长起势/慢镜/慢环绕/装饰词；写距离缩短、突然变向与短促接触 |
| 动作拥挤或自动减少 | 精简装饰与不相关微动作，保留一条攻防链；不再加密 |
| 漂浮滑行 | 补支撑、重心、路线、落点，确认首帧轮廓与武器可见性 |
| 受力发软 | 补接触方向、肩胯与脚步变化及必要材质反馈 |
| 切镜后重新站好 | 继承尾帧速度、姿态与武器位置，改动作匹配切 |
| 特效遮住攻防 | 降低无关效果，保留接触点、轨迹与角色轮廓 |

结合专业模块diagnostics逐轮复测动作、镜头或参考素材的一类变量。无实际视频时仅检查文字可执行性，不承诺生成效果。
