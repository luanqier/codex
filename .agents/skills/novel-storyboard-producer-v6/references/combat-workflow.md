# V6 打斗专用流程

本流程决定打斗脚本、对白、参考图与验收。普通剧情仍使用核心流程。

## 执行
1. 接收适配层的原文、状态、时长、资产、对白与既定结果。忠实改编补足动作连接，不新增决定胜负的力量或后果。
2. 用 [动作与摄影](combat-direction.md) 组织“发起—应对—可见结果—下一拍”，明确加速、接触和落点。按需要调用 [特效库](effects-visual-library.md)，写实场景不强制调用。
3. 写首尾连续、无空档与重叠的时间线，合计精确等于本段时长。区间长度由动作和说话需要决定，不机械等分；较长战斗拆为自然连续段。开口对白可与能够并行的动作共用时间。
4. 保留参战角色实际开口的对白，标角色、时间、声色与开口状态；第三方解说、旁白和内心独白不出声。用可见表演承接内心信息，不强制新增台词。
5. 只交专用脚本及独立人物、场景、必要道具参考图；批准图优先复用并复制到交付目录。制作打斗段或完整章时交实际图片；脚本-only不扩展出图。工具不可用时标未完成，不用绘图提示词冒充实际参考图。
6. 检查剧情、动作、时间、身份、声音与参考绑定；记录结束状态、完成范围和接续点。

## 独立脚本格式
```text
# 打斗段 F01｜15秒
视觉设定：项目画风、画幅、光线与人物版本。
参考绑定：角色与场景对应的实际批准路径；脚本草案未就绪时标待生成。
开场状态：双方站位、朝向、距离、武器持有手与环境障碍。
战斗目标与既定结果：原文支持的双方目的、能力限制及结果。

动作时间线
[00.0–02.2s] 空间与第一轮动作，写发起、目标、应对、接触和落点；镜头跟随对象与同步声随动作描述。
[02.2–06.0s] 承接余势，改变攻守或位置，按剧情保留[角色｜声色｜开口]：对白。
[06.0–11.5s] 继续攻防与局势变化，呈现加速、必要反馈及新状态。
[11.5–15.0s] 确认既定结果，保留可承接的速度、姿态、位置和声音余韵。

结束与接续：位置/朝向、余势或停稳状态、持有物、能力/体力、环境变化、结果和下一段入口。
```

上述只是结构示例，不固定15秒、四个区间或该时长分配。成品按素材填写，不复制示例动作。无对白时省略对白，不自动补喊招。对白可融入时间线或段级对白条目，后者仍需标时间、角色与开口。
参考图按其职责绑定人物身份、场景或道具，不描述不存在的已批准文件。打斗不生成宫格、逐镜拼图、逐镜配图或“图1是参考分镜图”声明；镜头数不决定参考图数量。

## 目录与封包
- 打斗段/第NN段/打斗脚本.txt
- 打斗段/第NN段/参考图/人物、场景与必要道具图片

生产索引记录文戏/打斗类型、顺序、段ID、规划时长、永久路径、状态及接续点。混合章节ZIP包括两类目录、音色档案与索引；总资产按核心流程单独保存，不重复塞入每章。

## 文本与交付验收
- 每次攻击有目标、轨迹、应对和结果；下一拍能由前一拍的余势、空当或距离变化发生。
- 没有无目的反复收招复位、匀速慢演或用慢镜填时长；支撑、重心、受力方向及落点可辨认。
- 屏幕方向、速度、持有手、武器数量、能力资源、环境状态与首尾接续连贯。
- 对白来自参战角色实际开口；第三方解说、旁白和内心独白音轨均不加入。语音与动作可在预算时间内执行，复杂动作不因对白机械变慢。
- 时间线覆盖全段，声音节点与可见动作同步；图片或完整包交付时身份图和场景图实际存在且绑定正确，脚本草稿只核查角色/场景映射计划并标待生成。
- 文件齐全、全章顺序与总时长正确、压缩包可打开。旧文戏六字段与宫格检查仅验文戏，不冒充全章验收。

脚本草案可保留待生成资产，完整包缺必需图片则标未完成；未生成视频不声称动作和速度已通过成片验证。
