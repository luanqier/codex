# V6 打斗适配层

本模块负责文戏与打斗的交接。动作、对白和交付以本Skill内的 [combat-workflow.md](combat-workflow.md) 与 [combat-direction.md](combat-direction.md) 为准，不读取同级V5或action-comic-drama的旧禁对白规则。

## 进入与回传
进入前复用原文范围、段ID/时长、风格画幅、批准资产路径及版本、双方目标、站位朝向、距离、武器持有手、能力限制、环境状态、既定结果、需保留的开口对白和下一文戏入口。缺失且影响胜负或身份时才追问；无攻防的普通走动仍是文戏。
混合段按动作边界拆分，索引保留其在全章中的顺序和时长。已批准拆分不能因调用模块擅自重排。
结束后回传双方位置/朝向、速度与姿态、持有物、能力/体力、环境变化、结果、保留信息和下一段入口；记录脚本及图片路径、完成状态与未完成项，再恢复文戏。

## 模块约束
- 不改变原文因果、胜负、能力、身份或关键结果；禁锢、受伤、疲惫和资源不足等限制必须影响动作，不能为了连招自动解除。
- 参战角色开口对白可以保留；第三方解说、旁白和内心独白不出声。不能把内心句改成角色开口而改变原意；用可见表演或前后文戏承接必要信息。
- 无声表演无法明确传达关键内心信息，且当前范围没有前后文戏空间时，保留无声导演意图并在生产索引或交付说明标记信息表达风险；不擅自改成对白、加旁白或扩展剧情。
- 打斗交独立时间线与参考图，不回填文戏六字段，不生成宫格或图1参考分镜声明。用户只要脚本则不扩展出图。
- 默认单套紧凑连续攻防；不执行上游的标准/极速速度补问、固定交锋数、固定镜头数或自动三套输出。用户明确要求对比时再提供方案。
- 时间、动作密度与声音需可执行；特效与镜头不能遮掉接触和应对，也不引入未批准的破坏或新力量。
