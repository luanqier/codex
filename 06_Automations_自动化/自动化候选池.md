# 自动化候选池

这里记录所有可能值得自动化的流程。不要马上自动化，先看它是否真的重复、稳定、有价值。

| 流程 | 触发条件 | 频率 | 价值 | 复杂度 | 推荐动作 |
| --- | --- | --- | --- | --- | --- |
| 每日碎片整理 | 每天有新 Inbox 内容 | 每日 | 高 | 低 | 先手动跑一周，再接 n8n |
| 每周复盘 | 每周日或周一 | 每周 | 高 | 中 | 先模板化 |

## 判断标准

一个流程值得自动化，通常满足：

1. 重复出现 3 次以上。
2. 输入输出格式相对稳定。
3. 手动处理让你明显分心。
4. 出错成本可控。
5. 自动化后能释放注意力。

## 2026-05-27 自动化候选：每日 Inbox 整理

流程名称：每日 Inbox 整理
触发条件：每天需要复核 `00_Inbox_碎片收集/今日收集.md`，并判断是否需要继续分流
当前手动步骤：
1. 读取自动化记忆，避免重复判断
2. 读取 Inbox 与核心系统笔记
3. 对照项目、Skill、决策、自动化候选与复盘记录判断去向
4. 追加一份 dated triage draft 到 `07_Reviews_复盘/每日整理.md`
5. 更新自动化记忆，记录当天结论与下次关注点
频率：每日
价值：高
复杂度：低到中
出错成本：低到中；主要风险是误分流或制造重复笔记
推荐工具：Codex automation + Markdown 追加写入
是否现在自动化：继续半自动运行，不接更复杂外部编排
下一步：再累计 3 到 5 次样本，确认检查清单与输出格式稳定后再决定是否进一步自动化

## 2026-06-03 自动化候选：每日任务指挥台

流程名称：每日任务指挥台
触发条件：用户每天面对群消息、课程、视频课件、资料和杂项任务，感到选择压力过大
当前手动步骤：
1. 读取当天 Inbox、课程清单、群消息摘要、视频课件待办
2. 判断用户当天精力状态
3. 把事项分成必须今天做、可以推进、可交给 AI、可延后、可放弃
4. 选出今天 1 到 3 件重点
5. 为每件事拆出最小下一步
频率：每日
价值：高
复杂度：低
出错成本：低；只生成建议，不直接删除或对外发送
推荐工具：Codex Automation / 手动口令
是否现在自动化：建议先手动跑 3 天，再开启每日草稿
下一步：每天用“启动每日任务指挥台”口令测试输出是否真的省力

## 2026-06-03 自动化候选：群消息提炼

流程名称：群消息提炼
触发条件：用户复制群消息、社群讨论、评论区内容或 OCR 文本到 Inbox
当前手动步骤：
1. 收集群消息文本
2. 提取高价值内容、选题、行动项和噪音
3. 判断是否进入选题池、项目库、Inbox 或自动化候选
4. 给出最值得处理的 1 到 3 条
频率：高
价值：高
复杂度：中
出错成本：低到中；不要自动回复群消息，不要自动公开发布
推荐工具：群消息提炼 Skill + OCR + n8n Webhook
是否现在自动化：先半自动，避免一开始接入私密聊天读取
下一步：先用手动复制或截图 OCR 的方式跑 3 次

## 2026-06-03 自动化候选：课程目录筛选与消化

流程名称：课程目录筛选与消化
触发条件：用户有大量百度课程、网课、教程或训练营资料需要学习
当前手动步骤：
1. 收集课程名称、目录、链接或课件
2. 判断课程与当前目标的关系
3. 标出必学、跳过、暂存章节
4. 把必学章节转成学习块、可产出内容和行动项
频率：高
价值：高
复杂度：中
出错成本：低；只做学习建议和摘要
推荐工具：课程消化 Skill + 浏览器剪藏 + 音视频转写
是否现在自动化：先手动跑 3 门课，再决定是否批处理
下一步：选 1 门当前最有压力的课程做样本

## 2026-06-03 自动化候选：视频课件生产流水线

流程名称：视频课件生产流水线
触发条件：用户需要把选题、课程内容、群消息观点转成视频或课件
当前手动步骤：
1. 选择主题或素材
2. 判断内容形式
3. 生成视频脚本、课件大纲、素材清单
4. 拆出最小录制动作
5. 录制后归档脚本、素材和成品路径
频率：高
价值：高
复杂度：中
出错成本：中；脚本和大纲可自动，最终表达和发布需人工确认
推荐工具：视频课件生产流水线 Skill + Codex + 文档/演示工具
是否现在自动化：先自动生成草稿，不自动发布
下一步：用一个群消息选题或课程章节生成首个视频/课件草稿

## 2026-06-03 自动化候选：统一收集入口

流程名称：统一收集入口
触发条件：用户在网页、课程、群消息、文件夹、手机端看到想保存的内容
当前手动步骤：
1. 复制链接、文本、文件路径或截图说明
2. 添加来源和时间
3. 写入 `00_Inbox_碎片收集/今日收集.md`
4. 等待每日整理或任务指挥台处理
频率：每日多次
价值：高
复杂度：中
出错成本：低；只写 Inbox，不改核心笔记
推荐工具：Obsidian Web Clipper / n8n Webhook / 文件夹监听 / 手机快捷入口
是否现在自动化：建议优先实施
下一步：先确定 1 个入口作为主入口，避免入口太多反而增加负担
