# n8n 接入蓝图

## n8n 在系统中的角色

n8n 是外部工具连接层，不是大脑。它负责把信息从外部系统送进 AI-Brain，也负责把已稳定的重复流程自动化。

## 第一批推荐流程

### 1. Webhook 碎片收集

输入：手机快捷指令、浏览器插件、表单、其他工具调用 Webhook。

流程：

```text
Webhook 接收内容
  → 加时间戳和来源
  → 写入 AI-Brain/00_Inbox_碎片收集/今日收集.md
  → 可选：通知 Codex 或等待每日整理
```

### 2. 文件夹监听

输入：指定资料文件夹中新出现的 PDF、图片、视频、文档。

流程：

```text
监听文件夹
  → 记录文件名、路径、时间、类型
  → 写入 Inbox
  → 后续由 Codex 判断是否需要整理
```

### 3. 网页资料收集

输入：网页链接。

流程：

```text
接收链接
  → 抓取标题和摘要
  → 写入 Inbox
  → 标记为待资料整理
```

### 4. 每日 Inbox 整理触发

输入：定时任务。

流程：

```text
每天固定时间
  → 读取 Inbox
  → 调用 AI 整理
  → 生成整理建议
  → 写回 AI-Brain 或等待确认
```

### 5. 每周复盘触发

输入：每周定时任务。

流程：

```text
每周固定时间
  → 汇总本周 AI-Brain 内容
  → 生成复盘草稿
  → 写入 Reviews
```

## 接入优先级

1. Webhook 碎片收集。
2. 文件夹监听。
3. 每日 Inbox 整理。
4. 每周复盘。
5. 与邮件、网盘、聊天工具集成。

## 安全规则

- n8n 可以自动写 Inbox，但不要自动删除源文件。
- 重要决策、原则库、自我模型更新需要人工确认。
- 对外发送、公开发布、调用付费服务前必须确认。
- 所有自动化先跑 1 周日志模式，再开启真实写入。
