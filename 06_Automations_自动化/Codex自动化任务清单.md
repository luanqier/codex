# Codex 自动化任务清单

这里记录适合用 Codex Automations 定时执行的任务。当前建议先手动触发 7 天，再开启定时。

## 自动化 1：每日 Inbox 整理建议

频率：每天晚上

任务：

1. 读取 `00_Inbox_碎片收集/今日收集.md`。
2. 按 `$ai-brain-manager` 规则分类。
3. 生成写入建议。
4. 不直接删除原始内容。
5. 需要重大修改时等待用户确认。

推荐提示词：

```text
请按 AGENTS.md 和 $ai-brain-manager 工作。读取今天的 Inbox 内容，生成整理建议：哪些进入项目库、决策日志、Skill、自动化候选池、原则库。除非用户已授权，不要删除原始内容。
```

## 自动化 2：每周复盘草稿

频率：每周一次

任务：

1. 读取本周 Inbox、项目库、决策日志、Skill、自动化候选池。
2. 总结重复主题。
3. 识别 Skill 候选和自动化候选。
4. 生成每周复盘草稿。
5. 给出下周最重要的 3 件事。

推荐提示词：

```text
请按 AGENTS.md 和 $ai-brain-manager 工作。根据本周 AI-Brain 内容生成每周复盘草稿，包含重复主题、推进项目、卡住项目、重要决策、需要升级的 Skill、值得自动化的流程和下周 3 件重点。
```

## 自动化 3：Skill 升级检查

频率：每周一次

任务：

1. 查找重复主题。
2. 判断是否达到 3 次出现。
3. 给出 Skill 草稿。
4. 更新 Skill 索引前等待确认。

## 自动化 4：自动化候选排序

频率：每周一次

任务：

1. 读取自动化候选池。
2. 按价值、频率、复杂度、风险排序。
3. 推荐最值得先做的一个流程。
4. 给出 Codex/n8n 实施方案。

## 当前建议

先不要开启全自动写入。先开启“生成草稿/建议”，等判断稳定后再允许写入。
