# 自动化实施路线图

## 当前阶段

当前处于“半自动验证期”。目标是用 Codex + `$ai-brain-manager` 先跑通流程，再把稳定流程交给 Codex Automation 或 n8n。

## 阶段 1：规则自动化，已完成

已具备：

- `AGENTS.md`
- `.agents/skills/ai-brain-manager/SKILL.md`
- AI-Brain 固定目录结构
- 信息分流规则
- 核心 Skill 草稿

使用方式：打开 AI-Brain workspace 后，用 `$ai-brain-manager` 管理内容。

## 阶段 2：触发式自动化，当前使用

人工触发，AI 自动分流。

常用触发口令：

```text
用 $ai-brain-manager 沉淀本次对话到 AI-Brain。
```

```text
用 $ai-brain-manager 整理这些碎片，并判断应该写入哪里。
```

## 阶段 3：Codex 定时自动化

适合做：

| 自动化 | 频率 | 动作 | 是否建议现在开启 |
| --- | --- | --- | --- |
| 每日 Inbox 整理 | 每天晚上 | 读取今日收集，生成整理建议 | 第 1 周后开启 |
| 每周复盘 | 每周一次 | 生成每周复盘草稿 | 第 1 周后开启 |
| Skill 升级检查 | 每周一次 | 找出重复主题和 Skill 候选 | 第 2 周后开启 |
| 自动化候选检查 | 每周一次 | 找出最值得自动化的流程 | 第 2 周后开启 |

## 阶段 4：n8n 外部采集自动化

适合接入：

- 网页链接
- RSS
- 邮箱
- 表单
- 文件夹监听
- 网盘
- Notion/飞书/Slack/微信转存
- Webhook

第一批 n8n 流程建议：

1. Webhook 收集碎片到 Inbox。
2. 文件夹监听，把新文档/图片/视频路径写入 Inbox。
3. 每日定时调用 AI 整理 Inbox。
4. 每周生成复盘草稿。

## 阶段 5：大脑层自动化

后续接入 LangGraph：

- 决策流程状态机
- 多角色分析
- 人工确认节点
- 长期任务追踪
- 复盘后自动更新原则和 Skill

后续接入 Letta/Mem0：

- AI 长期偏好记忆
- 用户画像更新
- 历史决策检索
- 个性化建议

## 开启自动化的条件

一个流程满足下面条件，再自动化：

1. 已手动跑过 3 次以上。
2. 输入输出格式稳定。
3. 能明显节省注意力。
4. 出错成本可控。
5. 需要人工确认的环节已经明确。

## 当前最推荐的自动化顺序

1. 每周复盘草稿。
2. 每日 Inbox 整理建议。
3. 网页/资料链接收集。
4. 文件夹监听。
5. Skill 升级检查。
6. 自动化候选排序。
