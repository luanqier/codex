# 当前目标

## 90 天目标

- 搭建一个能稳定整理碎片信息、辅助决策、沉淀 Skill 的 AI 工作团队系统。
- 跑通从 Inbox 到知识整理、决策日志、Skill 升级、每周复盘的基础流程。
- 接入自动化流程，减少重复劳动。

## 本月重点

- 完成 AI-Brain 的第一版结构。
- 开始每天收集碎片信息，并用信息整理 Skill 处理。
- 明确最值得自动化的 3 个重复任务。

## 本周重点

- 接入几个skill帮我减轻现在的工作量
- 补全自我模型和当前目标。
- 跑通第一次碎片整理。
- 建立 Skill索引、决策日志和每周复盘的使用习惯。

## 暂时不做

- 暂时不急着接入复杂多 Agent 系统。
- 暂时不急着部署 LangGraph、Letta、n8n。
- 暂时不追求全自动，先用手动流程验证需求。

## 判断标准

一个新任务是否值得做，先检查：

1. 是否推动 90 天目标。
2. 是否能减少重复劳动。
3. 是否能帮助整理碎片信息或沉淀 Skill。
4. 是否能帮助我研究、探索和做决策。
5. 是否现在必须做，还是可以先手动验证。
6. 是否有复利价值。
7. 是否只是噪音或即时满足。
8. 是否能通过小实验验证。
