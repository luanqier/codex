# 自媒体与课程生产系统

## 项目目标

把群消息、短视频教程、网盘课程、个人经验和项目案例，转化为可发布的自媒体内容和可录制课程，减少重复整理和临时起稿的压力。

## 当前生产链路

```text
群消息 / 短视频教程 / 网盘课程 / 项目经验
  -> AI 初筛
  -> 选题池
  -> 脚本或课件大纲
  -> 最小录制块
  -> 发布/归档
  -> 复盘升级 Skill
```

## 内容来源

- 群消息中的高频问题
- 短视频教程中的可复用方法
- 百度网盘课程中的必学章节
- 当前项目中的真实案例
- 用户自己的判断、经验和方法

## 生产规则

1. 不从零想选题，先从已有输入里提炼。
2. 每次只做一个最小产出。
3. 一条素材尽量复用为：短视频、课件页、图文、长期知识。
4. 先生成粗稿，再优化表达。
5. 录课前先确认结构，不直接追求完整课程。
