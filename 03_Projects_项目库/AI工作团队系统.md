# AI 工作团队系统

## 项目目标

搭建一个可进化的个人 AI 工作团队系统，用来整理碎片信息、辅助决策、沉淀 Skill、减少重复劳动，并逐步接入画图、编程和自动化能力。

## 当前阶段

阶段：最小可用系统 + 半自动运行

已经具备：

- AI-Brain Obsidian 仓库
- AGENTS.md
- `$ai-brain-manager` Codex Skill
- 自我模型 v0.1
- 当前目标 v0.1
- Skill 索引
- 决策日志
- 自动化候选池
- 每周复盘模板

## 当前重点

1. 连续 7 天使用 Inbox 收集和整理碎片。
2. 遇到选择写入决策日志。
3. 发现重复方法时升级为 Skill。
4. 发现重复流程时进入自动化候选池。
5. 第 7 天生成第一次每周复盘。

## 下一步

- 跑通每日流程。
- 跑通每周复盘。
- 选择第一个自动化流程。
- 再决定是否接入 Codex Automation 或 n8n。

## 成功标准

- 每天能稳定沉淀至少 3 条碎片。
- 每周能生成一份复盘。
- 每周至少发现 1 个 Skill 候选或自动化候选。
- 1 个月内接入第一个外部自动化流程。

## 2026-06-07 SkillOS 对齐落地

今天将外部推荐的 SkillOS 架构对齐到现有 AI-Brain，不推倒重建，采用最小工程化增强：

- 保留现有核心：Obsidian 长期记忆、Codex 深度执行、Skill 手册、n8n 自动化蓝图。

- 新增 Skill 执行日志，让每次重要使用都能沉淀反馈和失败类型。
- 新增 Skill 评估用例，先覆盖紧急减负总控、信息整理、自动化判断。
- 新增 Skill提炼器、Agent输出评估、安全审查三个支撑 Skill。

当前阶段定义：

```text
AI-Brain MVP
  -> SkillOS 最小工程化骨架
  -> 统一快速收集入口
  -> 真实样本跑 7 天
  -> 再决定是否接 n8n / Qdrant / Agents SDK / LangGraph
```
