# 课程消化 Skill

## 触发条件

当用户需要学习百度课程、网课、教程、训练营、直播回放或资料包时触发。

典型口令：

```text
用课程消化 Skill 处理这门课，帮我判断哪些值得学、怎么学、能产出什么。
```

## 输入

- 课程名称
- 课程目录
- 课程链接
- 课件、PDF、讲义或截图
- 课程音视频转写文本
- 用户当前项目和学习目标

## 处理步骤

1. 先判断课程和当前目标的关系：
   - 直接服务当前项目
   - 可作为未来素材
   - 只适合快速扫过
   - 暂时不学
2. 按章节做三层筛选：
   - 必学章节
   - 可跳过章节
   - 以后再看的章节
3. 对必学章节提炼：
   - 核心观点
   - 可直接应用的方法
   - 可变成视频/课件/文章的素材
   - 需要实践的动作
4. 给出学习顺序和最小学习块。
5. 判断是否应该进入项目库、资料库、Skill 或自动化候选池。

## 输出格式

```text
课程判断：
推荐处理方式：精学 / 跳学 / 扫目录 / 暂存 / 放弃

为什么：

必学章节：
1. 

可跳过章节：
1. 

可产出内容：
- 视频选题：
- 课件素材：
- 方法论：
- 行动项：

今日最小学习块：

学习后要沉淀到：
- Inbox：
- 项目库：
- 资料库：
- Skill：
```

## 检查标准

- 不默认要求用户学完整门课。
- 每次只安排一个低阻力学习块。
- 输出必须包含可产出内容，避免学习变成纯消耗。
- 如果课程与当前目标关系弱，要明确建议暂存或放弃。

## 可自动化方向

- 课程目录自动写入 Inbox。
- 课程转写文本自动摘要。
- 每周自动生成课程学习优先级。
- 把课程片段转成视频/课件素材卡。
