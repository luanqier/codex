# 视频课件生产流水线 Skill

## 触发条件

当用户需要做视频、录课件、准备脚本、整理素材、拆分选题或复用已有内容时触发。

典型口令：

```text
用视频课件生产流水线 Skill，把这个主题变成可录制的脚本和课件大纲。
```

## 输入

- 主题或选题
- 群消息提炼出的观点
- 课程消化后的知识点
- 用户已有素材、案例、图片、录音、视频
- 目标受众和发布平台

## 处理步骤

1. 判断内容更适合做：
   - 短视频
   - 长视频
   - 课件
   - 直播提纲
   - 图文笔记
2. 把主题拆成生产资产：
   - 一句话主题
   - 目标受众
   - 3 到 5 个核心点
   - 开场钩子
   - 案例或故事
   - 结尾行动
3. 生成可录制版本：
   - 视频脚本
   - 课件大纲
   - 逐页幻灯片要点
   - 素材清单
4. 判断哪些部分可复用到其他内容。
5. 给出最小录制动作。

## 输出格式

```text
推荐内容形式：

一句话主题：

目标受众：

结构：
1. 开场：
2. 核心点：
3. 案例：
4. 结尾：

视频脚本草稿：

课件大纲：

素材清单：
- 

可复用资产：
- 

今天最小生产动作：
```

## 检查标准

- 输出必须能直接进入录制或制作，而不是停留在想法。
- 默认先生成粗稿，不追求一次完美。
- 每个主题都要尽量留下可复用资产。
- 如果主题过大，先拆成 1 个可完成的小片段。

## 可自动化方向

- 从选题池自动生成脚本草稿。
- 从课程笔记自动生成课件大纲。
- 从群消息高频问题自动生成视频选题。
- 录制后自动生成发布摘要和归档说明。
