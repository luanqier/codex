# 安全审查 Skill

## 触发条件

当任务涉及高风险动作、敏感信息或不可逆修改时触发。

高风险动作包括：

- 对外发送邮件、消息、评论或公开发布内容。
- 删除、覆盖、移动重要文件。
- 调用付费服务、付款、下单、提交表单。
- 处理身份证、电话、地址、账号、合同、医疗、财务等敏感信息。
- 自动访问封闭平台、绕过平台限制或批量抓取私密内容。

## 输入

- 用户请求。
- 涉及的文件、工具、平台或外部对象。
- 计划执行的动作。
- 是否已有用户明确授权。

## 处理步骤

1. 判断动作风险等级：低 / 中 / 高。
2. 判断是否可逆。
3. 判断是否涉及隐私、敏感数据、财务、医疗、法律或外部发布。
4. 判断是否已有用户明确授权。
5. 对高风险动作，先生成草稿、预览或建议，不直接执行。
6. 明确需要用户确认的点。
7. 如果任务可降级，给出低风险替代方案。

## 输出格式

```text
风险等级：
风险来源：
是否可逆：
是否需要用户确认：
建议执行方式：
低风险替代方案：
```

## 检查标准

- 没有确认，不删除、覆盖或外发重要内容。
- 自动化只能先处理低风险、可回滚、可检查的动作。
- n8n 可以自动写 Inbox，但不自动更新原则库、自我模型、决策结论或对外发送。
- 涉及私人平台数据时，优先使用手动导入、截图 OCR 或官方 API。

## 可自动化方向

- 在自动化候选进入实施前自动跑一次安全审查。
- 在 n8n workflow 从“日志模式”切换到“真实写入”前检查风险。
- 在外发邮件、发布内容、删除文件前插入人工审批节点。
