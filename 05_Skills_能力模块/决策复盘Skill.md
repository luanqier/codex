# 决策复盘 Skill

## 触发条件

当遇到以下情况时触发：

- 工具选型
- 项目取舍
- 是否投入时间或金钱
- 是否自动化某个流程
- 是否开始/暂停/删除一个项目

## 输入

一个需要判断的问题，以及当前背景。

## 处理步骤

1. 明确真正的问题是什么。
2. 读取当前目标和原则。
3. 列出 2 到 3 个可选方案。
4. 分析目标相关性、机会成本、风险和可逆性。
5. 给出推荐方案。
6. 设计最小下一步实验。
7. 写入决策日志。

## 输出格式

```text
问题：
背景：
目标相关性：
可选方案：
推荐方案：
选择理由：
风险：
可逆性：
下一步小实验：
复盘日期：
```

## 检查标准

- 有没有先判断目标相关性。
- 有没有说明机会成本。
- 有没有给出最小实验，而不是直接重投入。
- 有没有留下未来可复盘的预期。

## 可自动化方向

重要决策不建议全自动，但可以自动生成决策记录草稿，由你确认。
