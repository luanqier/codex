# 信息整理 Skill

## 触发条件

当出现以下内容时触发：

- 零散想法
- 聊天记录
- 网页摘录
- 语音转文字
- 临时待办
- 项目灵感

## 输入

原始碎片信息，可以很乱，不需要先整理。

## 处理步骤

1. 提取核心意思。
2. 判断它属于哪个项目或主题。
3. 提炼行动项。
4. 判断是否需要进入决策日志。
5. 判断是否有长期知识价值。
6. 判断是否可能沉淀成 Skill 或自动化。

## 输出格式

```text
摘要：
标签：
关联项目：
行动项：
可沉淀知识：
是否需要决策：
是否值得自动化：
下一步：
```

## 检查标准

- 摘要是否一句话说清。
- 行动项是否具体可执行。
- 是否连接到已有项目。
- 是否识别了潜在决策。
- 是否避免把无价值噪音永久保存。
