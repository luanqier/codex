用途：把分散的 Skill 从“可阅读手册”升级为“可检索、可评估、可自动化的能力资产”。

## 字段说明

| 字段 | 含义 |
| --- | --- |
| Skill | Skill 名称 |
| 版本 | 当前手册版本，先用 `0.1.0` 起步 |
| 状态 | 待设计 / 草稿 / 试运行 / 稳定 |
| 主触发 | 最常见的触发场景 |
| 风险 | 低 / 中 / 高 |
| 可自动化 | 否 / 部分 / 是 |
| 工具依赖 | 当前或未来可能调用的工具 |
| 评估状态 | 未建 / 已建用例 / 已跑样本 / 可回归 |

## Loader 规则

1. 先根据用户输入判断任务类型、风险等级和需要的输出。
2. 先看本注册表，不直接加载所有 Skill 全文。
3. 选择 1 个主 Skill，必要时选择 1 到 2 个辅助 Skill。
4. 读取对应 Skill 文件，再按需读取项目、目标、决策或自动化上下文。
5. 任务完成后，如果结果重要，追加到 [[Skill执行日志]]。
6. 如果输出不稳定，补充 [[Skill评估用例]] 或更新对应 Skill 的检查标准。

3. 让后续 n8n、MCP、Agents SDK 接入时有可迁移的清单。
