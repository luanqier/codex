# 群消息提炼 Skill

## 触发条件

当用户需要从微信群、社群、评论区、私域社群或聊天记录中提炼有价值内容时触发。

典型口令：

```text
用群消息提炼 Skill 处理这段群消息，帮我提炼选题、行动项和可沉淀知识。
```

## 输入

- 群消息文本
- 聊天截图 OCR 后的文本
- 用户手动摘出的重点消息
- 群内链接、图片、文件、视频线索
- 用户对某个群的关注目标

## 处理步骤

1. 先判断这批消息的用途：选题、资料、机会、任务、情绪噪音或无价值信息。
2. 把消息分成：
   - 可变成视频/文章/课件的选题
   - 可进入项目库的资料
   - 需要立刻处理的行动项
   - 值得继续观察的人、问题或趋势
   - 噪音或暂不处理内容
3. 对每个高价值片段提炼：
   - 原始观点
   - 可复用表达
   - 适合的内容形式
   - 是否关联当前项目
4. 判断是否需要写入 Inbox、项目库、Skill、决策日志或自动化候选池。
5. 给出今天最值得处理的 1 到 3 条。

## 输出格式

```text
群消息概览：

高价值内容：
1. 
2. 
3. 

可做选题：
1. 选题：
   适合形式：
   为什么值得做：
   下一步：

行动项：
1. 

需要继续观察：
- 

噪音/暂不处理：
- 

建议写入：
- Inbox：
- 项目库：
- Skill：
- 自动化候选：

今天只建议做的一件事：
```

## 检查标准

- 不要求读完所有群消息，只提炼对用户有用的东西。
- 输出必须帮用户减少判断负担，而不是制造更多待办。
- 每次最多推荐 3 条高价值内容，默认只推进 1 条。
- 对情绪化、争吵型、低价值闲聊要明确标记为噪音。
- 不自动对外回复群消息，除非用户明确要求。

## 可自动化方向

- 群消息截图 OCR 后自动进入 Inbox。
- 手动复制群消息到 Webhook，由 n8n 写入 Inbox。
- 每日定时生成群消息摘要草稿。
- 每周从群消息中汇总重复问题，形成选题池。
