# 每周复盘 Skill

## 触发条件

每周结束，或用户说“生成每周复盘”时触发。

## 输入

本周 AI-Brain 中的 Inbox、项目库、决策日志、Skill、自动化候选池和原则库。

## 处理步骤

1. 汇总本周重复出现的主题。
2. 判断哪些项目真正推进了。
3. 找出卡住的项目。
4. 汇总重要决策和待复盘决策。
5. 找出可升级的 Skill。
6. 找出值得自动化的流程。
7. 给出下周最重要的 3 件事。

## 输出格式

```text
本周主题：
推进项目：
卡住项目：
重要决策：
新增知识：
需要升级的 Skill：
值得自动化的流程：
下周 3 件重点：
需要更新的原则：
```

## 检查标准

- 复盘要产生行动，不只是总结。
- 每次复盘至少检查一个 Skill 或自动化候选。
- 每次复盘都要连接当前目标。

## 可自动化方向

第 1 周后，可以用 Codex Automation 每周生成复盘草稿。
