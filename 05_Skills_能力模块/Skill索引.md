# Skill索引

Skill 是你的 AI 系统持续进化的能力单元。每个 Skill 都应该回答：什么时候触发、怎么处理、输出什么、如何检查、是否值得自动化。

| Skill | 状态 | 触发条件 | 输出 | 是否可自动化 |
| --- | --- | --- | --- | --- |
| 信息整理 Skill | 草稿 | 有碎片信息、聊天记录、链接、灵感 | 摘要、标签、关联项目、行动项、长期知识 | 是 |
| 决策复盘 Skill | 草稿 | 遇到选择、方向判断、工具选型 | 方案比较、风险、下一步小实验、决策日志 | 部分 |
| 自动化判断 Skill | 草稿 | 重复任务出现 3 次以上 | 自动化价值判断、流程草案、接入工具建议 | 是 |
| 编程 Skill | 待设计 | 需要读代码、改代码、跑测试、生成项目 | 实施计划、代码修改、验证结果 | 部分 |
| 画图 Skill | 待设计 | 需要流程图、架构图、分镜、UI 草图 | Mermaid/Figma/图片提示词/图表方案 | 部分 |

## Skill 升级规则

1. 同类任务出现 3 次，创建 Skill 草稿。
2. Skill 使用 3 次后，补充检查清单。
3. Skill 使用 5 次后，考虑自动化。
4. Skill 输出不稳定时，补充示例、反例和边界条件。
5. 每周复盘时检查是否有 Skill 需要升级、合并或删除。

## 当前优先级

1. 先跑通信息整理 Skill。
2. 再跑通决策复盘 Skill。
3. 最后再接自动化判断 Skill。

## 2026-06-07 SkillOS 落地优先级

1. 先用 [[Skill注册表]] 管理现有 Skill，不急着上数据库。
2. 每次重要任务后，用 [[Skill执行日志]] 记录是否真的省力。
3. 先给 [[紧急减负总控Skill]]、[[信息整理Skill]]、[[自动化判断Skill]] 建评估用例。
4. 优先试用 [[Skill提炼器Skill]]、[[Agent输出评估Skill]]、[[安全审查Skill]]，让系统能自我改进但不失控。
5. 本周仍不追求全自动，先跑真实样本。
