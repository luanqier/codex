# Skill提炼器 Skill

## 触发条件

当出现以下情况时触发：

- 用户说“以后这类事情都这么做”。
- 同类任务、同类碎片或同类流程出现 3 次以上。
- 某个回答方式明显好用，值得复用。
- 某个失败反复出现，需要固化成检查清单。

## 输入

- 一段对话、任务记录、碎片集合或失败案例。
- 已有相关 Skill 文件或 Skill索引。
- 用户对结果的反馈。

## 处理步骤

1. 判断这是一次性经验，还是可复用方法。
2. 提取触发条件、输入、处理步骤、输出格式和检查标准。
3. 查找是否已有相似 Skill，优先更新旧 Skill，不轻易新建重复 Skill。
4. 如果新建，先写成草稿，不直接承诺自动化。
5. 如果更新，优先追加“版本记录”或“检查标准”，不覆盖用户原文。
6. 判断是否需要新增评估用例。
7. 更新 [[Skill注册表]] 和 [[Skill索引]]。

## 输出格式

```text
是否值得形成 Skill：
原因：
建议处理：
- 新建 / 更新 / 暂存

Skill 草稿：
- 名称：
- 触发条件：
- 输入：
- 处理步骤：
- 输出格式：
- 检查标准：
- 可自动化方向：

需要更新的文件：
下一步：
```

## 检查标准

- 不把一次性灵感硬做成 Skill。
- 不重复创建已有 Skill。
- Skill 必须能回答“什么时候触发、怎么处理、输出什么、如何检查”。
- 可自动化方向必须保守，先验证再自动化。

## 可自动化方向

- 每周复盘时扫描本周重复主题，生成 Skill 候选清单。
- 从 [[Skill执行日志]] 中提取失败模式，建议更新对应 Skill。
- 当用户确认后，自动追加 Skill 草稿和注册表条目。
