# 自动化判断 Skill

## 触发条件

当某个流程重复出现 3 次以上，或者你明显觉得它消耗注意力时触发。

## 输入

一个重复任务或跨工具流程。

## 处理步骤

1. 描述当前手动流程。
2. 判断输入和输出是否稳定。
3. 判断频率和价值。
4. 判断出错成本。
5. 判断适合用 n8n、脚本、Dify、MCP 还是暂时手动。
6. 生成自动化候选记录。

## 输出格式

```text
流程名称：
触发条件：
当前手动步骤：
频率：
价值：
复杂度：
出错成本：
推荐工具：
是否现在自动化：
下一步：
```

## 检查标准

- 不为了自动化而自动化。
- 优先自动化稳定、重复、高价值、低风险的流程。
- 对高风险流程保留人工确认。

## 可接入工具

- n8n
- Codex
- Dify
- MCP
- Webhook
- 本地脚本
