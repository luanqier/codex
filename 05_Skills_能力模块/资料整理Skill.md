# 资料整理 Skill

## 触发条件

当需要整理链接、网页、文档、图片、视频、论文、教程或聊天记录时触发。

## 输入

- 链接
- 文档路径
- 图片路径
- 视频链接或视频文件
- 网页摘录
- 聊天记录
- 其他资料来源

## 处理步骤

1. 识别资料类型和来源。
2. 提取主题和核心信息。
3. 判断它关联哪个项目或目标。
4. 提炼可行动内容。
5. 判断是否值得长期保存。
6. 判断是否可能升级为 Skill、决策或自动化候选。
7. 给出保存位置建议。

## 输出格式

```text
资料类型：
来源：
摘要：
关键观点：
关联项目：
行动项：
可沉淀知识：
是否需要决策：
是否可形成 Skill：
建议写入位置：
```

## 检查标准

- 不只是摘要，要判断用途。
- 不把无关资料永久保存。
- 能连接到项目、目标或 Skill。
- 能给出下一步行动。

## 可自动化方向

- 浏览器剪藏到 Inbox。
- 文件夹监听新资料。
- 视频/文档自动生成摘要草稿。
- 每日资料整理建议。
