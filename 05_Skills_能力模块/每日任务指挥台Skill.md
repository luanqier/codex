# 每日任务指挥台 Skill

## 触发条件

当用户感到信息过载、任务太多、课程太多、视频课件生产压力大，或需要 AI 帮忙安排当天行动时触发。

典型口令：

```text
启动每日任务指挥台，帮我从今天的内容里选出最该做的 3 件事。
```

## 输入

- 今日 Inbox
- 群消息提炼结果
- 课程学习清单
- 视频/课件待办
- 用户当天精力状态
- 截止时间和必须完成的事项

## 处理步骤

1. 先识别今天的精力状态：低电量、正常、高产出。
2. 把所有事项分成：
   - 必须今天做
   - 可以推进
   - 可以委托 AI 先处理
   - 可以延后
   - 可以放弃
3. 选出今天最值得做的 1 到 3 件事。
4. 对每件事给出最小下一步。
5. 把能交给 AI 的部分拆出来，例如摘要、脚本、大纲、整理、命名、归档。
6. 给出当天收尾口令。

## 输出格式

```text
今日精力判断：

今天只抓这 3 件事：
1. 
2. 
3. 

先交给 AI 处理：
1. 

你亲自处理：
1. 

延后/放弃：
- 

最小下一步：

晚上收尾口令：
```

## 检查标准

- 输出必须减少用户选择压力。
- 不把所有事情都列成待办。
- 默认保护用户精力，优先安排能产生复利的事。
- 每次都要明确“AI 先干什么，用户再确认什么”。

## 可自动化方向

- 每天早上自动生成任务指挥台草稿。
- 每天晚上自动读取 Inbox 并生成第二天建议。
- 周复盘时统计哪些任务总是重复出现，升级为 Skill 或自动化候选。
