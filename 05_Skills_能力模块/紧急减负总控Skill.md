# 紧急减负总控 Skill

## 触发条件

当用户同时面对群消息、短视频教程、百度网盘课程、课程录制、自媒体选题、资料碎片和日常任务，感到信息过载或需要 AI 帮忙决定今天做什么时触发。

典型口令：

```text
启动紧急减负总控，帮我从群消息、短视频教程、课程、自媒体和录课任务里筛出今天最该做的事情。
```

## 关联 Skill

- 群消息提炼 Skill
- 资料整理 Skill
- 课程消化 Skill
- 视频课件生产流水线 Skill
- 每日任务指挥台 Skill
- 自动化判断 Skill

## 输入

- `00_Inbox_碎片收集/群消息收集入口.md`
- `00_Inbox_碎片收集/短视频教程收集入口.md`
- `00_Inbox_碎片收集/课程评估入口.md`
- `03_Projects_项目库/自媒体与课程生产系统.md`
- 今日必须完成事项
- 用户精力状态

## 处理步骤

1. 先判断用户今天的精力状态：低电量、正常、高产出。
2. 读取四类输入：群消息、短视频教程、课程、内容生产。
3. 先过滤噪音，只保留高价值内容。
4. 把内容分成：马上行动、交给 AI、可做选题、可做课程素材、暂存、放弃。
5. 对网盘课程和短视频教程先判断值不值得学，不默认完整学习。
6. 对可产出的内容，调用视频课件生产流水线 Skill，拆成最小脚本、课件页或录制块。
7. 选出今天只做 1 到 3 件事。
8. 判断哪些重复流程可以进入自动化候选池。
9. 给出晚上收尾口令。

## 检查标准

- 输出必须减负，不制造更多待办。
- 默认只推荐 1 到 3 件事。
- 学习必须服务于项目、内容产出或长期能力，不做无目标学习。
- 自媒体和录课优先使用已有素材，不从零硬想。
- 所有自动化建议都必须先经过手动验证。

## 可自动化方向

- 每天早上生成减负指挥台草稿。
- 每天晚上处理四个入口并生成明日建议。
- 群消息截图 OCR 后进入群消息入口。
- 短视频链接和课程目录自动进入对应入口。
- 每周自动生成选题池、课程优先级和自动化候选排序。
