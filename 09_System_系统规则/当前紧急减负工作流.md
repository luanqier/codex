# 当前紧急减负工作流

目标：把群消息、短视频教程、百度网盘课程、课程录制、自媒体生产这些高频压力源，变成一套每天可执行、可筛选、可沉淀、可自动化的流程。

## 总原则

```text
先收集，不先判断；先筛选，不先学习；先产出，不先完美；先半自动，不先全自动。
```

## 五类压力源怎么处理

| 压力源 | 放入哪里 | 调用 Skill | 输出 |
| --- | --- | --- | --- |
| 群消息 | `群消息收集入口.md` | 群消息提炼 Skill | 选题、行动项、噪音过滤 |
| 短视频教程 | `短视频教程收集入口.md` | 资料整理 + 课程消化 | 是否值得看、核心方法、可产出内容 |
| 百度网盘课程 | `课程评估入口.md` | 课程消化 Skill | 精学/跳学/暂存/放弃 |
| 课程录制 | `自媒体与课程生产系统.md` | 视频课件生产流水线 Skill | 脚本、课件大纲、最小录制块 |
| 自媒体 | `自媒体与课程生产系统.md` | 视频课件生产流水线 Skill | 选题、脚本、图文、发布摘要 |

## 每天早上，启动指挥台

```text
启动紧急减负总控。读取群消息入口、短视频教程入口、课程评估入口、自媒体与课程生产系统，结合我的当前目标和精力状态，帮我决定今天只做哪 1 到 3 件事。先给建议，不要直接写入。
```

## 白天，只收集不深想

- 群消息复制到 `群消息收集入口.md`。
- 短视频链接、标题、转写片段放到 `短视频教程收集入口.md`。
- 网盘课程目录、文件列表、试看感受放到 `课程评估入口.md`。
- 想录的课、想做的内容放到 `自媒体与课程生产系统.md`。

## 晚上，一次性整理

```text
用紧急减负总控 Skill 处理今天四个入口。请筛掉低价值内容，只保留高价值内容，告诉我哪些该沉淀、哪些该放弃、明天只做什么。先给草稿，不要直接写入。
```

## 课程判断规则

- A 类：直接服务当前项目，精学。
- B 类：有素材价值，跳学，只提炼可产出内容。
- C 类：只看目录，暂存。
- D 类：放弃。

不要默认学完整门课。

## 自媒体/录课规则

每次只做一个最小生产块：

- 1 个短视频脚本
- 1 页课件
- 1 个案例讲解
- 1 个开场钩子
- 1 个结尾行动

不要一开始就做完整课程。

## 未来自动化顺序

2. 群消息 OCR/复制入口。
3. 短视频链接收集入口。
4. 课程目录自动评估。
5. 选题池自动生成。
6. 视频/课件脚本草稿自动生成。
