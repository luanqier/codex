# 信息分流与升级规则

## 一句话规则

```text
一次性内容进 Inbox，重要取舍进决策，重复方法变 Skill，稳定重复流程进自动化。
```

## 分流规则

| 类型 | 判断标准 | 写入位置 |
| --- | --- | --- |
| 碎片 | 一次性的想法、链接、资料、图片、视频、临时问题 | `00_Inbox_碎片收集` |
| 项目资料 | 和一个长期项目直接相关 | `03_Projects_项目库` |
| 决策 | 涉及取舍、优先级、投入、暂停、删除、工具选择 | `04_Decisions_决策日志` |
| Skill | 可复用的方法，未来会反复使用 | `05_Skills_能力模块` |
| 自动化候选 | 重复、稳定、耗时、规则明确的流程 | `06_Automations_自动化` |
| 自我模型 | 用户偏好、边界、长期风格 | `01_Self_Model_自我模型` |
| 原则 | 可指导未来判断的经验 | `09_System_系统规则/原则库.md` |
| 复盘 | 周期性总结、项目回顾、系统改进 | `07_Reviews_复盘` |

## 升级规则

1. 同类碎片出现 3 次，提出 Skill 候选。
2. Skill 使用 5 次，提出自动化候选。
3. 自动化候选连续 2 周仍然高频，进入实施。
4. 重要决策必须留下预期结果和复盘日期。
5. 新原则必须来自实际经验，不写空泛口号。

## 降噪规则

- 不确定时先进入 Inbox。
- 低价值、不可复用、无行动意义的信息可以只做临时记录。
- 每周复盘时清理过期碎片。
- 不要把所有资料都变成知识，先判断它是否服务于目标。

## AI 判断顺序

当用户给出一段信息时，AI 先问：

1. 这是什么类型的信息？
2. 它是否关联当前目标或项目？
3. 它是否涉及选择？
4. 它是否会重复出现？
5. 它是否可以形成 Skill？
6. 它是否适合自动化？
7. 最小下一步是什么？
