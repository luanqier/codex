# AI-Brain 完整运行流程

这是当前阶段的完整流程。核心原则：先让 AI-Brain 稳定运转，再逐步接入自动化和更复杂的大脑层。

## 总体架构

```text
输入层：对话、想法、链接、文档、图片、视频、网页、项目资料
  ↓
分流层：Codex + $ai-brain-manager 判断内容类型
  ↓
记忆层：Inbox / 项目库 / 决策日志 / Skill / 自动化候选池 / 原则库 / 复盘
  ↓
进化层：每周复盘，升级 Skill，筛选自动化候选
  ↓
执行层：Codex / n8n / Dify / LangGraph / Letta / 画图工具 / 编程工具
```

## 当前阶段的目标

1. 每天能收集和整理碎片。
2. 遇到选择能进入决策日志。
3. 重复方法能升级为 Skill。
4. 重复流程能进入自动化候选池。
5. 每周能复盘并更新系统。
6. 后续可以自然接入 n8n、Codex Automation、LangGraph 和 Letta。

## 每日流程

每天只做 5 到 10 分钟。

1. 把今天产生的想法、链接、资料、任务、问题丢给 Codex。
2. 使用 `$ai-brain-manager` 判断内容应该写入哪里。
3. Codex 先给写入建议。
4. 你确认后再写入 AI-Brain。
5. 当天结束时，让 Codex 总结今日行动项和可能的自动化候选。

推荐口令：

```text
用 $ai-brain-manager 整理今天这些内容。先给写入建议，不要直接改文件：
...
```

确认后：

```text
确认，按刚才的建议写入 AI-Brain，并告诉我改了哪些文件。
```

## 每次对话结束流程

当一次 Codex 对话有价值时，使用：

```text
用 $ai-brain-manager 沉淀本次对话到 AI-Brain。
```

Codex 应该判断是否产生：

- Inbox 碎片
- 项目资料
- 决策日志
- Skill 更新
- 自动化候选
- 原则库更新
- 行动项

## 每周流程

每周固定做一次，建议周日晚上或周一上午。

1. 读取本周 Inbox、决策日志、Skill、自动化候选池、项目库。
2. 总结本周重复出现的主题。
3. 判断哪些内容应该升级为 Skill。
4. 判断哪些流程值得进入自动化候选池。
5. 更新每周复盘。
6. 给出下周最重要的 3 件事。

推荐口令：

```text
用 $ai-brain-manager 根据本周 AI-Brain 内容生成每周复盘。先给我草稿，确认后写入。
```

## 每月流程

每月一次，检查系统是否仍然服务于目标。

1. 回顾 90 天目标。
2. 检查项目库中哪些项目应该继续、暂停或删除。
3. 检查 Skill 是否太多、太散或重复。
4. 选择 1 到 3 个流程进入自动化实施。
5. 更新原则库和当前目标。

## 自动化阶段

当前先使用半自动流程。自动化按下面顺序推进：

1. Codex 规则自动化：AGENTS.md + `$ai-brain-manager`。
2. Codex 触发式自动化：你说“沉淀本次对话”后自动分流。
3. Codex 定时自动化：每日整理 Inbox，每周生成复盘。
4. n8n 外部自动化：网页、邮箱、文件夹、表单、Webhook 自动进入 Inbox。
5. LangGraph 大脑层：复杂决策流、状态机、多角色分析。
6. Letta/Mem0 记忆层：长期 Agent 记忆。

## 不做什么

- 不要一开始全自动写入所有内容。
- 不要把所有碎片永久保存。
- 不要没有人工确认就删除、覆盖或对外发送重要内容。
- 不要为了自动化而自动化。

## 成功标准

7 天后，至少产生：

- 20 条以上 Inbox 碎片
- 3 条以上决策日志或决策候选
- 3 个以上 Skill 候选
- 3 个以上自动化候选
- 1 份每周复盘
