# 系统迁移与恢复指南

这个文件用于在没有原始对话记录时，重新理解、迁移、恢复 AI-Brain 系统。

## 一句话说明

AI-Brain 是一个以 Obsidian 为长期记忆、Codex 为工作台、Skill 为能力模块、自动化候选池为进化入口的个人 AI 工作团队系统。

## 必要组件

### 1. Obsidian 仓库

保存长期记忆和系统说明。核心是 Markdown 文件，因此可以迁移到任意电脑或同步工具。

### 2. Codex 工作规则

根目录：

```text
AGENTS.md
```

作用：告诉 Codex 如何读取 AI-Brain、如何分流内容、如何写入和保护已有内容。

### 3. Codex Skill

路径：

```text
.agents/skills/ai-brain-manager/SKILL.md
```

作用：让 Codex 可以用 `$ai-brain-manager` 处理沉淀对话、整理碎片、写决策日志、升级 Skill、识别自动化候选。

### 4. 系统规则

核心说明位于：

```text
09_System_系统规则
```

尤其重要：

- `AI-Brain完整运行流程.md`
- `信息分流与升级规则.md`
- `Codex日常口令手册.md`
- `系统迁移与恢复指南.md`

## 迁移到新电脑

1. 复制整个 `AI-Brain` 文件夹到新电脑。
2. 用 Obsidian 打开新位置的 `AI-Brain` 文件夹。
3. 用 Codex 打开同一个文件夹作为 workspace。
4. 如果路径变了，更新这些文件中的旧路径：
   - `START_HERE.md`
   - `AGENTS.md`
   - `.agents/skills/ai-brain-manager/SKILL.md`
   - 本文件
5. 对 Codex 说：

```text
请读取 START_HERE.md 和 AGENTS.md，检查 AI-Brain 是否迁移成功。先不要修改文件。
```

## 迁移到其他 AI 工具

如果换成 Claude Code、Cursor、Windsurf 或其他 Agent 工具：

1. 先让新工具读取 `START_HERE.md`。
2. 再读取 `AGENTS.md`。
3. 再读取 `09_System_系统规则/AI-Brain完整运行流程.md`。
4. 告诉它：

```text
请把 AGENTS.md 当作你的项目规则，把 ai-brain-manager/SKILL.md 当作你的工作流程参考。不要删除或覆盖用户内容；默认先给写入建议，确认后再写入。
```

如果新工具不支持 Codex Skill，也没关系：把 `.agents/skills/ai-brain-manager/SKILL.md` 当作普通说明文档读即可。

## 恢复系统上下文

如果完全忘了这个系统怎么用，按顺序读：

1. `START_HERE.md`
2. `AGENTS.md`
3. `09_System_系统规则/AI-Brain完整运行流程.md`
4. `09_System_系统规则/Codex日常口令手册.md`
5. `05_Skills_能力模块/Skill索引.md`
6. `06_Automations_自动化/自动化实施路线图.md`

然后让 AI 输出：

```text
请根据这些文件，重建我当前 AI-Brain 的系统说明、目录用途、日常流程、自动化路线和下一步建议。
```
