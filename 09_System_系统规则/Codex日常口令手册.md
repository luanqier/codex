# Codex 日常口令手册

## 启动口令

```text
请按 AGENTS.md 工作，并使用 $ai-brain-manager 管理我的 AI-Brain。
```

## 整理碎片

```text
用 $ai-brain-manager 整理下面这些碎片。先给写入建议，不要直接改文件：
...
```

## 确认写入

```text
确认，按刚才的建议写入 AI-Brain，并告诉我改了哪些文件。
```

## 沉淀本次对话

```text
用 $ai-brain-manager 沉淀本次对话到 AI-Brain。
```

## 判断放哪里

```text
用 $ai-brain-manager 判断这段内容应该进入 Inbox、项目库、决策日志、Skill、自动化候选池、原则库还是复盘：
...
```

## 形成 Skill

```text
用 $ai-brain-manager 判断这件事是否应该形成 Skill。如果应该，请给 Skill 草稿，先不要写入。
```

## 记录决策

```text
用 $ai-brain-manager 把这个选择整理成决策日志。先给草稿，确认后写入：
...
```

## 判断自动化

```text
用 $ai-brain-manager 判断这个流程是否值得自动化，并给出自动化候选记录：
...
```

## 每周复盘

```text
用 $ai-brain-manager 根据本周 AI-Brain 内容生成每周复盘。先给草稿，确认后写入。
```

## 自动化实施

```text
用 $ai-brain-manager 从自动化候选池里选出最值得先做的 1 个流程，并设计 n8n/Codex Automation 实施方案。
```

## 启动每日任务指挥台

```text
启动每日任务指挥台。读取今天的 Inbox、课程、群消息和视频课件待办，帮我决定今天最该做什么，哪些先交给 AI 处理，哪些延后或放弃。
```

## 群消息提炼

```text
用群消息提炼 Skill 处理下面这些群消息，帮我提炼选题、行动项、可沉淀知识和噪音内容：
...
```

## 课程消化

```text
用课程消化 Skill 处理这门课。先判断它是否值得学，再帮我分出必学章节、可跳过章节、可产出内容和今日最小学习块：
...
```

## 视频课件生产

```text
用视频课件生产流水线 Skill，把下面这个主题或素材变成可录制的视频脚本、课件大纲和素材清单：
...
```

## 读取状态

```text
用 $ai-brain-manager 检查当前 AI-Brain 的状态，告诉我下一步最应该做什么。先不要修改文件。
```


## 系统健康检查

```text
请读取 START_HERE.md 和 AGENTS.md，检查 AI-Brain 的目录、关键文件、Skill、自动化蓝图是否完整。请只检查，不要修改文件，并告诉我下一步最应该做什么。
```

## 迁移后恢复

```text
请读取 START_HERE.md、AGENTS.md 和 09_System_系统规则/系统迁移与恢复指南.md，帮我确认这个 AI-Brain 迁移后是否还能正常工作。先不要修改文件。
```
